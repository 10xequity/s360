## How to fill a placeholder safely

1. Search the repo for `class="tbd"`, replace the whole `<span class="tbd">…</span>` with the value.
2. `python scripts/preflight.py` — placeholder count goes down, problems stay 0.
3. Commit to `main`; Pages redeploys in about a minute.

## How shared blocks are edited now

The header (`[NAV]`…`</header>`) and footer (`[FT]`…`</footer>`) on all eight pages are **regenerated by a script**, not hand-edited: `scripts/patch_v03.py` holds the `nav()` and `FOOTER` templates. To change a nav item or footer line, edit the template and re-run; the script is idempotent. Hand-editing eight copies is how the sister sites accumulated drift.

## Trap log

- Bash heredocs with prose or code die on quoting; write scripts to disk with the Write tool and run them. Bit three times this project.
- Wix Media Manager listing exceeds the 50 KB tool cap; page 12 files at a time with `paging.cursor`.
- Pages with `<video>` and tall viewports time out headless screenshots; strip the video, capture viewport-size.
- HTML `height` attributes + CSS `width` only = distorted images. Keep `img{height:auto}`.
- Google Fonts by `<link>` caused CLS 0.34; self-hosted + preloaded fixed it.
- Inline `grid-template-columns` styles break phone breakpoints; use a class.
- A `.sec-light` section with dark cards inside makes inherited black text vanish; the technology benefits grid did this until it became a dark `.meter` section.
- White on brand red `#EF001D` is 4.49:1; fills use `#E0001B`, small red text on black uses `#FF2A3C`.
